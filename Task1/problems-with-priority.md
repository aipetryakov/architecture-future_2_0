# Проблемы

| Приоритет | Проблема | Детализация |
| - | -------- | ------- |
| 1 | Сложность независимого развития направлений | 1. Используются по большей части монолитные решения. |
| 2 | Сложные отчеты строятся часами. | 1. Очень много данных лежат в централизованном DWH. 2. Происходит большое кол-во трансформаций во время генерации отчетов. |
| 3 | DWH построен на базе SQL-сервера 2008 | 1. SQL-сервер не подходит для OLAP нагрузки. 2. Вендор прекратил поддержку данной версии в 2019 году |
| 4 | Большое кол-во бизнес-логики реализовано в SQL | 1. Сложность поддержки и читаемости. 2. Сложность тестирования. 3. Сложность независимого развития под разные направления. |
| 5 | Все данные компании лежать в одном SQL-сервере | 1. Сложно обеспечить безопасный доступ к данным. 2. Одно хранилище не лучшим образом подходит для различных типов данных и типов нагрузки. 3. DWH-структура не очень хорошо подходит для машинного обучения. 4. Сложность обработки неструктурированных данных. |
| 6 | Интерфейс для операторов в клинике построен на Power Builder | 1. Устаревшая технология. 2. Слабые возможности построения качественного UX и UI. 3. Сложность независимого развития под разные направления. |
