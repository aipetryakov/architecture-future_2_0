# Домены

1. Клиенты: профили пациентов
2. Медицина: истории болезней, диагнозы, результаты анализов, назначения
3. Финансы: счета, транзакции, кредиты, страховые полисы.
4. Персонал и инвентаризация: врачи, медсёстры, оборудование, его обслуживание.
5. Фармацевтика: каталог лекарств, остатки, заказы, поставки
6. Производство электронники: комплектующую, остатки, тех.процессы

# Логика разделения

1. Бизнес-ориентированность - каждый домен соответствует ключевым направлениям компании
2. Техническая независимость - разные команды могут работать параллельно, снижен риск влиянния одного домена на другой.
3. Медицинские данные (GDPR) изолированы от финансовых (PCI DSS).
4. Можно настроить индивидуальные политики доступа.
5. Гибкость интеграции новых партнёров (например, страховую компанию подключаем только к финансовому домену).
6. Данные между доменами передаются через стандартизированные события.

# Преимущества

1. Скорость изменений - более быстрый запуск новых фич
3. Безопасность	- минимизация утечек (контролируемый доступ данных одного домена к другому).
4. Конкурентоспособность - возможность быстрее адаптироваться к рынку.
